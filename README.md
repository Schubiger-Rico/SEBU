# SmartShop V5

Einkaufsliste nach dem Grundsatz „Alles kann, nichts muss“. Stand: Block 1–8 (Navigation, Produkte, LocalStorage, Letzte Produkte, Favoriten, Verlauf, Einstellungen, GPS-Einstellungen).

## Starten
`index.html` im Browser öffnen. Es wird nichts installiert, Daten bleiben lokal im Browser (localStorage).

## Veröffentlichen mit GitHub Pages
Repository → Settings → Pages → Branch `main`, Ordner `/ (root)`.
